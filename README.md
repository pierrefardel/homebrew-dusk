# Homebrew tap for Dusk

```sh
brew tap pierrefardel/dusk
brew trust pierrefardel/dusk
brew install --cask dusk
```

[Dusk](https://github.com/pierrefardel/dusk) updates itself afterwards. Dusk isn't notarized by Apple yet, so macOS blocks the first launch: go to **System Settings › Privacy & Security** and click **Open Anyway**, once.
